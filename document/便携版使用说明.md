# Seraphine 免费开源便携版

本版全部功能免费，直接运行，无需激活。

1. 下载完整 Windows 便携 ZIP，解压到普通目录。
2. 双击 `Seraphine.exe`；旁边的 DLL、`app`、`PyQt5`、`models` 等文件夹必须一起保留。
3. 打开英雄联盟客户端。装备经济与语音设置位于程序左侧。
4. 游戏视频设置选择「无边框」或「窗口」。进入对局后按住 Tab 查看经济差。
5. 语音输入：Enter 打开聊天 → 说话 → 检查或修改识别文字 → 自己按 Enter 发送；Esc 取消。

设置保存在当前用户的 `%APPDATA%/SeraphinePlus`。更新应用不会清除原有设置。语音识别在本机运行，录音不会上传。

单独的 EXE 不包含全部依赖。模型缺失时可在源码环境执行 `scripts/download_voice_model.py`，然后重新构建。

许可证、修改说明及相应版本源码随发行包提供。原作者说明见 `document/UPSTREAM_README.md`，语音组件说明见 `app/resource/voice/THIRD_PARTY_NOTICES.md`。
