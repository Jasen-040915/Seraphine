# 免费开源版构建与发行

需要 Windows x64 与 Python 3.12。先安装 `requirements-plus.txt`，再运行 `scripts/download_voice_model.py` 和 `build-plus.ps1`。

构建脚本使用经检查的 ASCII 路径联接，避免 Qt 构建工具在中文路径下丢失插件。默认输出 `dist/Seraphine`，其中包含主程序、独立按键服务、本地语音模型和许可证。可使用 `-OutputDirectory` 与 `-BuildDirectory` 分别指定输出和中间目录。

测试：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests
```

应用支持 `--self-test-full --self-test-voice`，在隔离配置目录中渲染真实界面并识别捆绑公开语音样本。诊断模式不启动真实键鼠监听或麦克风。游戏内聊天接收仍需实际对局确认。

源码与发行包排除：虚拟环境、Git 元数据、构建缓存、日志、截图、个人配置、诊断状态、旧授权、支付订单、数据库和私钥。语音模型通过下载脚本获取，保留其原许可。构建工具参见 `scripts/package_portable.py`，公开发布工具以经过审查的 Git 跟踪文件生成匹配源码包。

发布时保留根 `LICENSE`、`readme.md`、`MODIFICATIONS.md`、`document/UPSTREAM_README.md`、依赖许可及相应版本源码。
